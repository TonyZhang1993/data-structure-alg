## 题目

请实现一个函数,将一个字符串中的每个空格替换成"%20". 例如,当字符串为We Are Happy. 则经过替换之后的字符串为We%20Are%20Happy. 


## 思路


```js
function replaceSpace(s) {
  return s.replaceAll(' ', '%20')

  return s.split(' ').join('%20')

  return s.replace(/\s/g, '%20')
}


```

## 拓展

允许出现多个空格,多个空格用一个%20替换

用正则表达式找到连续空格进行替换

```js
function replaceSpace(str) {
    return str.replace(/\s+/g,'%20');
}


正则知识: 
()  []  {} 的区别
() 的作用是提取匹配的字符串. 表达式中有几个()就会得到几个相应的匹配字符串. 比如 (\s+) 表示连续空格的字符串. 
[] 是定义匹配的字符范围. 比如 [a-zA-Z0-9] 表示字符文本要匹配英文字符和数字. 
{} 一般用来表示匹配的长度,比如 \d{3} 表示匹配三个数字,\d{1,3} 表示匹配1~3个数字,\d{3,} 表示匹配3个以上数字. 

^ 和 $

^ 匹配一个字符串的开头,比如 (^a) 就是匹配以字母a开头的字符串
$ 匹配一个字符串的结尾,比如 (b$) 就是匹配以字母b结尾的字符串
^ 还有另个一个作用就是取反,比如[^xyz] 表示匹配的字符串不包含xyz
i 忽略大小写
g 全局匹配, 若没有只匹配第一个

/^ I am tony $/g

4, \d  \s  \w  .

\d 匹配一个非负整数, 等价于 [0-9]
\s 匹配一个空白字符
\w 匹配一个英文字母或数字,等价于[0-9a-zA-Z]
.  匹配除换行符以外的任意字符,等价于[^\n]

## 以正则为调用方

- test则是用来检测字符串是否匹配某一个正则表达式
/\d+/.test("123") ; //true

- exec 正则执行 【返回一个包含匹配结果的数组，或者在没有匹配时返回 null】
var re = /^(\d{3})-(\d{3,8})$/;
re.exec('010-12345'); // ['010-12345', '010', '12345']

匹配成功时：返回一个数组，包含以下元素：
0：匹配到的整个字符串。
1：第一个捕获组（如果有的话）。
2：第二个捕获组（如果有的话），以此类推。
index：匹配结果在原字符串中的起始位置。
input：原始的输入字符串。

如果正则表达式没有全局标志 (/g)，exec 方法会只返回第一次匹配的结果。

匹配失败时：返回 null。

## 以字符串为调用方

- match是获取正则匹配到的结果,以数组的形式返回
"186a619b28".match(/\d+/g); // ["186","619","28"]

- search 输出匹配的位置
let str = "abcdef";
str.search(/bcd/)   // 输出结果: 1
//  返回值:  返回 str 中第一个与 regexp 相匹配的子串的起始位置.
```
